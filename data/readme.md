# Dataset

Os arquivos originais dos datasets utilizados no projeto **não são armazenados neste repositório**.

Isso evita a redistribuição indevida de dados de terceiros e mantém o repositório leve.

## Dataset utilizado

O dataset definitivo será registrado nesta seção após a conclusão da etapa de seleção.

As informações documentadas deverão incluir:

* nome;
* autores;
* instituição;
* URL oficial;
* número de imagens;
* número de instâncias;
* classes;
* tipo de anotação;
* licença/termos de uso;
* data de acesso.

## Estrutura esperada

Após o download, os dados deverão seguir a estrutura definida pelos notebooks de preparação.

Exemplo:

```text
data/
├── raw/
├── processed/
├── train/
├── val/
└── test/
```

Os diretórios contendo os dados reais estão incluídos no `.gitignore`.

## Importante

Não faça upload dos datasets de terceiros para este repositório sem verificar previamente suas condições de redistribuição.
